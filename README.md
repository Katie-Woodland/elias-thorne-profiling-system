# elias-thorne-profiling-system
A ready-to-use psychological profiling system (Dr. Elias Thorne) for everyday people. Run it on yourself first to surface your own biases, then on leaders/public figures or events. Outputs a Trustworthiness Index and Heuer-matrix calibration notes. Free to use with credit — never for commercial purposes. Created by Katie Woodland (@wookat1983).
